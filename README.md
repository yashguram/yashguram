## 📌 Featured Projects

### 🌦️ Weather App

An object-oriented Vanilla JavaScript weather application that fetches current weather information using the Open-Meteo APIs.

**Key Concepts:** Fetch API, async/await, OOP, DOM manipulation, error handling

**Tech Stack:** HTML, CSS, JavaScript, Open-Meteo API

---

### 👤 GitHub Profile Finder

A Vanilla JavaScript application that searches for GitHub users and displays their public profile information using the GitHub Users API.

**Key Concepts:** REST API, fetch, async/await, loading states, error handling

**Tech Stack:** HTML, CSS, JavaScript, GitHub API

---

### 📝 PHP and MySQL Content Management System

A complete CMS with a public website and an admin dashboard.

The application includes authentication, post management, category management, user management, comment moderation, search, pagination, image upload, and CRUD operations.

**Tech Stack:** PHP, MySQL, Bootstrap, JavaScript, jQuery

---

### ⚛️ React Steps App

A React mini-project created to practise state management, event handling, conditional rendering, and step-based navigation.

**Tech Stack:** React, JavaScript, CSS

---

### 📅 React Date Counter

A React application that calculates past and future dates based on a user-controlled step and count value.

**Key Concepts:** useState, functional state updates, conditional rendering, JavaScript Date object

**Tech Stack:** React, JavaScript, CSS

---

### 🧳 Far Away Packing List

A React travel packing list project created to practise reusable components, controlled forms, props, state, and list rendering.

**Tech Stack:** React, JavaScript, CSS
